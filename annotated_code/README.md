# Meet to meet — построчные пояснения к исходному коду

В этой папке находятся версии `main.py`, `database.py` и `notifications.py` с пояснениями на тех же строках.

Количество физических строк в каждом файле сохранено. Комментарии добавлены в конце исполняемых строк, где это синтаксически допустимо.

**Ограничение Python:** строки внутри многострочных литералов (например, SQL-запросов в тройных кавычках) являются содержимым строки, а не исполняемым кодом. Добавление `#` внутрь такого литерала изменило бы SQL/текст и могло бы сломать программу. Поэтому эти строки оставлены без inline-комментариев; пояснение находится на строке закрытия литерала. Пустые строки также не являются строками кода.

Эти файлы предназначены для изучения. Рабочие исходники проекта не изменяются.
