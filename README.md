# Meet to meet

**Meet to meet** — простое настольное приложение на Python для планирования встреч, онлайн-конференций и созвонов. Проект подготовлен как учебная практическая работа.

## Возможности

- календарь с выбором даты;
- добавление, просмотр, изменение и удаление встреч;
- хранение даты, времени начала и окончания, места или ссылки, описания и заметок;
- предупреждение о пересечении встреч по времени;
- поиск по названию, месту и описанию;
- системные уведомления о приближающихся встречах (пока приложение запущено);
- экспорт всего календаря в CSV или TXT;
- горячие клавиши для основных действий;
- настройки светлого/тёмного оформления, формата времени, напоминаний и сочетаний клавиш;
- автоматическое создание базы данных SQLite при первом запуске.

## Требования

- Python 3.10 или новее;
- Windows, Linux или macOS с графической средой;
- PyQt6.

## Установка и запуск

1. Установите Python.
2. Откройте терминал в папке проекта.
3. (Рекомендуется) создайте виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

4. Активируйте его:

   **Windows:**

   ```powershell
   .venv\\Scripts\\activate
   ```

   **Linux/macOS:**

   ```bash
   source .venv/bin/activate
   ```

5. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

6. Запустите приложение:

   ```bash
   python main.py
   ```

## Горячие клавиши по умолчанию

| Действие | Сочетание |
|---|---|
| Добавить встречу | Ctrl+N |
| Изменить встречу | Ctrl+E |
| Удалить встречу | Delete |
| Перейти к сегодняшнему дню | Ctrl+T |
| Экспорт календаря | Ctrl+Shift+E |
| Поиск | Ctrl+F |

Сочетания можно изменить в меню **Файл → Настройки**.

## База данных

Используется SQLite — встроенная база данных, которой не нужен отдельный сервер. Файл `meet_to_meet.db` создаётся автоматически **в корневой папке проекта**, рядом с `main.py` и `database.py`. Его можно открыть через DB Browser for SQLite или SQLiteStudio.

При первом запуске новой версии программа проверяет старое расположение базы `~/.meet_to_meet/meet_to_meet.db`. Если файл найден, а база рядом с проектом ещё не создана, старый файл копируется в новую папку. Исходная база остаётся на месте, поэтому существующие встречи и настройки не теряются.

Файлы SQLite (`*.db`, `*.db-shm`, `*.db-wal`, `*.sqlite`, `*.sqlite3`) добавлены в `.gitignore` и не отправляются в GitHub.

Таблица `meetings` содержит записи календаря. Таблица `settings` хранит настройки программы.

## Примечание об уведомлениях

Уведомления отображаются через системный трей, пока приложение запущено. Поддержка и внешний вид системных уведомлений зависят от операционной системы и её настроек.
